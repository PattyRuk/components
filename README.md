# DeltaDesign

## Overview

>This project is a modular, single-page web application built using React. The page showcases standard structural components including a header, a dynamic landing banner with custom button components, an aesthetic image grid layout, and a dynamic chronological footer.

## Features
**1. Clean Component Design**  
Instead of one massive file, the page is broken into isolated, reusable blocks (like a separate Header, PostForm, and Footer). If you fix a bug in the footer, it won't accidentally break the header.  
**2. Flexible Props System**  
We can pass custom "instructions" (called Props) to a single button component to change how it looks, such as telling it to be a primary action button or a secondary button without writing brand-new code for each one.  
**3. Smart Image Grid**  
The gallery uses a fast loop function to automatically read an array of images and display them on the gallery page.  
**4. Automated Date Tracking**  
The copyright text in the footer uses built-in JavaScript commands (new Date().getFullYear()) to automatically change the year on January 1st. You never have to manually update the code to keep it current.


## Technologies Used

* **HTML5** – Structure of the application
* **CSS** – Styling, layout, and responsiveness
* **JavaScript** – Game logic and interactivity
* **React:** Comprehensive framework interface layer.
* **JSX:** Declarative markup syntax optimization layout.
* **Node.js & npm:** External dependency management engine.
* **Git & GitHub Pages:** Deployment host systems managing deployment processing.
